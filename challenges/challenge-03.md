# Challenge 03: Evaluate it

Evaluate a support agent in the shared participant environment: run a golden
dataset against a baseline agent version, diagnose a failing case from its
trace, save a fixed version and compare both runs for improvements and
regressions.

This lab is independent and does not require work from another lab. Download and
extract the Student ZIP, then read the
[participant guide](../labs/03-evaluate/README.md) at
`labs/03-evaluate/README.md`, including its prerequisites, before starting.
