# Step 6 – Wrap up (2 min)

## ⚠️ Do not delete your environment

Your project **bootcamp**, the deployments, AI Search, storage and tracing are **shared by all six bootcamp labs**. The MicroHack platform removes the environment after the event.

You can keep your agent and toolbox – nothing to clean up.

## 🎉 What you built today

- A prompt agent in a ready-made Foundry project
- One **Toolbox** for the agent's assignment: File search, **Foundry IQ** on a pre-indexed AI Search index, Web search, Code interpreter and an existing **MCP** server
- **Traces** showing which tool ran
- **Model router** choosing a model per question
- The agent's **versions, endpoints and Publish options** – the way to Teams, Microsoft 365 Copilot and Copilot Studio in your own tenant

## Want more grounding later? (your own tenant)

The **SharePoint** tool (preview) grounds an agent on a SharePoint site with each user's own permissions. It needs a Microsoft 365 Copilot licence (or pay-as-you-go), cannot go in a toolbox, and does not work once the agent is published to Teams. See [SharePoint tool](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/sharepoint).
